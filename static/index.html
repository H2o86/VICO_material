✍️ Chiều GHI trực tiếp từ Web vào Google Sheet (Khi Admin Thêm/Sửa/Xóa trên Web)

Để khi Admin bấm Lưu/Xóa ngay trên giao diện Web mà dữ liệu tự động ghi thẳng vào Google Sheet của công ty (không cần mở Google Sheet), hãy thực hiện 1 lần duy nhất (mất ~1 phút):

  1. Mở File Google Sheet của Công ty $\rightarrow$ Trên menu chọn Tiện ích mở rộng (Extensions) $\rightarrow$ Apps Script.
  2. Bấm nút bên dưới để sao chép mã google_apps_script_sync.gs, dán đè vào cửa sổ Apps Script và bấm Lưu (Ctrl+S).
  3. Bấm nút Triển khai (Deploy) $\rightarrow$ Tùy chọn triển khai mới (New deployment) $\rightarrow$ Chọn loại Ứng dụng web (Web app) $\rightarrow$ Mục Ai có quyền truy cập chọn Bất kỳ ai (Anyone) $\rightarrow$ Bấm Triển khai.
  4. Copy đường dẫn URL ứng dụng web (https://script.google.com/macros/s/.../exec) dán vào ô bên dưới và bấm Lưu:
